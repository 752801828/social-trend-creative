# 项目总览与持续修改日志

## 项目边界

Social Trend Creative 是独立调度和创作服务。它拥有自己的管理页、计划任务、SQLite 数据库和图片目录；Flow2API 只负责生图，Gemini2API 负责原始热点获取、AI 拆分分类和提示词生成。

## 核心运行规则

- 流水线严格分成“原始热点获取 → AI 拆分分类形成热点池 → 随机热点形成提示词池 → 随机提示词生图”四阶段，Flow 不得直接消费热点记录。
- 自动调度默认关闭；手动完整流程执行全部四阶段，定时任务自动生图由独立开关控制。
- 热点获取覆盖全球事件、梗、情绪、审美、社群、季节节点和视觉符号；配置地区作为优先覆盖而非排他过滤。
- AI 可把一个宽泛原始热点拆成多个独立创意角度并分类；提示词阶段才选择具体物品及图案位置、比例、印刷处理和底色。
- Flow 输出杯子、手机壳、衣服、备胎罩等单一物品的完整效果图，且输入必须来自提示词池。
- 证据URL和发布时间为可选参考，不作为生图门禁；不得伪造来源。
- 不再设置最终保留数量上限；重复、空内容或明确不安全的候选仍会排除。
- “热点来源平台”只表示发现来源，不是图片发布渠道或目标平台。
- 管理API使用独立Bearer密钥；浏览器不持久化密钥。
- 密钥、Webhook和签名只从环境变量读取，不写入数据库或日志。

## 数据与部署

- SQLite：`data/trend-creative.db`
- 图片：`data/assets/<run>/<trend>/`
- 热点池：`trends`
- 提示词池：`prompt_pool`
- 生图记录：`generations`，通过 `prompt_id` 追踪实际使用的提示词
- 默认端口：`5920`
- Docker服务：`social-trend-creative`

## 持续修改日志

### 2026-08-11

- 建立独立海外社媒热点创作服务。
- 加入Gemini提示词发现、二次核验、JSON解析、来源与时间门禁。
- 加入人工选择热点后调用Flow生图、图片落盘、并发和失败记录。
- 加入每日固定时间调度、默认关闭的自动生图、连接检查和可选飞书通知。
- 新增编辑部风格管理页面、统计、轮次详情、来源链接、图片预览、终止和删除功能。
- 数据库入口在事务结束后显式关闭SQLite连接，避免Windows文件占用和长期句柄积累。
- Gemini非标准置信度或列表字段按不可信输入容错；重复生图时轮次统计改为数据库累计值。
- 新增根目录 `HANDOFF.md`，集中记录新对话启动语、项目边界、架构、配置、API、部署、验证和持续修改规则，后续开发转移到独立对话。
- 修复生图任务被终止后 generation/trend 状态残留为 `running/generating` 的问题；已成功的热点保留 `generated`，未成功的热点恢复终止前的可选状态，并记录取消原因。
- Flow 返回第三方图片地址时不再向第三方主机发送 Flow Bearer Key；仅同源图片下载携带上游鉴权。
- 新增终止状态恢复和第三方图片下载鉴权隔离的回归测试，测试总数由 8 项增至 10 项。
- 曾将热点发现和Flow提示词改为商品导向；该方向已在 2026-08-12 根据实际用途进一步纠正为热点视觉图案提取。
- 移除证据URL、发布时间和最终保留数量对生图的限制；真实来源仍作为可选参考保存，重复、空内容和不安全候选仍会排除。
- 管理页主操作曾改为手动获取后直接生图，且不受定时任务自动生图开关影响；按钮文案已在后续图案模式中继续调整。
- 移除有效配置中的 `final_count`，旧SQLite设置中的同名字段会在读取时忽略。
- 新增无证据和旧“超过最大数量”拒绝的回归测试，只有结构化的重复、空内容或不安全拒绝生效；测试总数增至 11 项。

### 2026-08-12

- 纠正创作目标：从“寻找商品并生成商品营销图”改为“提取社媒热点视觉信息并生成通用可印刷图案”。
- Gemini提示词改为提取事件、梗、情绪、审美和视觉符号；Flow提示词要求输出独立居中图案、保留安全边距，不生成任何商品载体或样机。
- 明确排除商标、版权角色、公众人物肖像、复制帖子和现有作品，降低图案商业使用风险。
- 管理页生成图片支持点击放大、键盘聚焦和原生对话框关闭；“传播版图”更名为“热点来源分布”，表示各平台命中的热点数量，并非发布渠道；测试总数增至 12 项。
- 热点提示词改为全球发现，地区配置降为优先覆盖；核验阶段为每条热点选择最匹配的杯子、手机壳、T恤、卫衣、帆布袋、抱枕、毯子、备胎罩等物品。
- Flow提示词改为把图案直接生成在单一物品上，要求图案自然服从曲面、褶皱、接缝和材质，并以清晰可检查的商业产品摄影形式呈现。
- 管理页“目标地区”更名为“优先地区（全球搜索）”，避免误解为只搜索所选国家；“热点来源平台”仍表示发现来源，不是物品类型或发布渠道。

### 2026-08-13

- 将原先耦合的发现/核验/直接生图流程拆为四个可独立运行的模块：热点获取、AI 拆分分类、提示词池生成和提示词池生图。
- 热点获取提示词只负责收集全球原始社媒信号，明确禁止在第一阶段选择商品或写最终生图提示词。
- 新增 AI 分类提示词：允许把一个宽泛热点拆成多个可独立使用的创意角度，合并重复并按文化、幽默、生活方式、季节、体育、科技、自然、旅行、食物、宠物、社会情绪等类别归池。
- 新增 `prompt_pool` SQLite 表，保存提示词、关联热点、状态、创建时间和 `used_count`；旧数据库启动时自动创建，无需手工迁移。
- 为 `generations` 增加兼容迁移列 `prompt_id`，每次 Flow 生图记录实际随机抽中的提示词；确认 Flow 只消费提示词池文本，不再直接由热点构造请求。
- 提示词生成支持从热点池随机抽取指定 `count`，同一轮次重复执行会追加新提示词；不指定数量时按 `candidate_count` 随机抽取，热点池不足时使用全部条目。
- 生图支持从提示词池随机抽取指定 `count`；未指定时沿用 `images_per_trend` 配置值作为“每轮随机生图数”。提示词可重复使用并累计使用次数。
- 已生成热点池的轮次禁止再次分类，避免 `trends` 替换对既有提示词和图片造成级联破坏；缺少前置池时各阶段会立即返回明确错误。
- 新增独立管理 API：`POST /api/runs/{id}/classify`、`POST /api/runs/{id}/prompts`；`POST /api/runs/{id}/generate` 改为随机消费提示词池，不再接收热点 ID。
- `POST /api/runs/discover` 现在只执行热点获取；`POST /api/runs/full` 串联四阶段。定时任务默认运行前三阶段，只有开启 `auto_generate` 才执行第四阶段。
- 管理页新增四阶段流程板、原始热点/热点池/提示词池/图片数量和分阶段按钮，展示提示词池内容，并移除已经失效的热点勾选框及“生成所选热点”操作。
- 设置文案将 `images_per_trend` 解释为“每轮随机生图数”，将 Gemini 核验模型解释为“分类/提示词模型”；保留内部配置字段以兼容旧 SQLite。
- 轮次详情对无法解析的旧 `raw_discovery` 响应容错；并发任务被拒绝时显式关闭未调度协程，避免运行时警告。
- 新增 `CONTEXT.md` 领域词汇表，统一 Raw trend、Trend-pool entry、Prompt-pool entry、Generation task 等术语。
- 新增提示词池分层及实际消费追踪的回归测试，测试总数由 12 项增至 13 项；同时通过 Python 编译检查。
