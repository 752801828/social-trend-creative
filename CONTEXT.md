# Domain glossary

- **Trend run**: One discovery cycle for a configured time window. A run owns discovery, verification, and optional generation work.
- **Trend candidate**: A social product, category, consumer need, aesthetic, use case, or marketing opportunity returned by Gemini.
- **Verified trend**: A candidate whose product angle and commercial visual direction have been reviewed by Gemini; evidence remains optional reference data.
- **Ready trend**: A non-duplicate, non-empty, safe product opportunity that may be generated immediately, with or without evidence.
- **Needs-review trend**: A legacy status retained for existing records; new discovery runs no longer use evidence availability to assign it.
- **Rejected trend**: A candidate removed only because it is duplicate, empty, or explicitly unsafe.
- **Generation task**: One Flow request for one trend and one selected image model.
- **Prompt-first discovery**: Asking Gemini Web to research public sources and return product opportunities. It is not treated as proof of live browsing; real evidence is preserved when available but is not a generation gate.
